# Karunada Kala – National Pride

Karunada Kala is an Android application developed to preserve and promote the traditional art forms of Karnataka using modern technology.

## Features
- Explore Karnataka traditional art forms
- View cultural information and visuals
- Simple and user-friendly UI
- Mobile responsive design
- Android APK support

## Technologies Used
- React / Vite
- Capacitor
- Android Studio
- JavaScript
- HTML/CSS

## APK Build
This project was converted into an Android APK using Capacitor and Android Studio.

## Installation
```bash
npm install
npm run dev
